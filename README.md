
# Universal Viewer

Universal Viewer is a desktop file browser and viewer built with Python and PySide6.

## Requirements

* Linux
* Python 3.12+
* Git
* uv

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/universal-viewer.git
cd universal-viewer
```

Install dependencies:

```bash
uv sync
```

## Run

Start Universal Viewer with:

```bash
uv run universal-viewer
```

## Supported Files

Universal Viewer can browse and open files such as:

* Images
* TIFF / TIF files
* PDF files
* Documents supported by the application

## Development

To run the application:

```bash
uv run universal-viewer
```

To update dependencies:

```bash
uv lock
```
